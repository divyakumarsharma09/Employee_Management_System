# Employee Management System

A simple and user-friendly **Employee Management System** developed using HTML, CSS, and JavaScript. This project provides an interactive interface to manage employee information efficiently.

## 🚀 Features

- Add new employee details
- View employee records
- Edit employee information
- Delete employee records
- Search and manage employees easily
- Responsive and user-friendly interface
- Dynamic data handling using JavaScript

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive design
- **JavaScript** – Functionality and dynamic operations
